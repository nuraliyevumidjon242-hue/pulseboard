Security

Security is a feature, not a checkbox.

Tokens that never persist

Access tokens live in memory only. Refresh tokens are httpOnly, hashed at rest and rotated on every use.

Replay detection

Reusing an old refresh token revokes every active session for that account automatically.

Tenant checks in middleware

Membership and permissions resolve before any store-scoped service runs.

Hardened by default

Helmet, rate limits on auth and sensitive actions, strict CORS and validated environment config.

Fail closed

Production refuses to boot with placeholder or development JWT secrets.

Auditable

Privileged actions are written to the activity log with actor, store and timestamp.
